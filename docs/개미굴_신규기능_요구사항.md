# 개미굴 — 신규 기능 요구사항

## 1. 개미 용어 사전 페이지

**메뉴**

- 사이드바 "단물 지도" 하단에 "개미 용어" 메뉴 신규 추가

**페이지 레이아웃**

- 기존 서브 페이지(비축 캘린더) 콘텐츠 영역과 동일한 사이즈로 구성

**콘텐츠 구성**

- 페이지 타이틀
- 난이도 필터 (칩/탭 형태): 전체 / 애기 개미 / 청년 개미 / 고참 개미
- 검색창 (용어 직접 검색)
- 용어 카드 리스트
  - 용어명
  - 난이도 배지
  - 뜻풀이 (난이도별로 설명 톤 다르게 — 용어 하나당 난이도별 설명
    버전을 데이터로 보유)
  - 연관 용어 태그

**비고**

- 기존 "오늘의 개미 용어 한 입"(메인 페이지)과 동일한 용어 DB를
  재사용, 여기에 난이도 필드 및 난이도별 설명 버전 추가 필요

---

## 2. 불개미 대장 챗 — 플로팅 버튼 전환

**현재 상태**

- 메인 페이지에만 고정 배치된 채팅 섹션

**변경 사항**

- 모든 페이지(서브 페이지 포함) 우측 하단에 플로팅 버튼(fixed
  position)으로 전환
- 버튼 클릭 시 채팅창 열림/닫힘 토글
- 열렸을 때 배경 블러 처리 없음 (페이지 콘텐츠는 그대로 노출된 채
  채팅창만 오버레이)
- 새 메시지 도착 시 버튼에 알림 배지(빨간 점 또는 숫자) 표시
- 채팅 UI 자체(말풍선, 상단 헤더 바)는 기존 메인 페이지 버전 그대로
  재사용, 컨테이너만 플로팅 패널 형태로 변경

## 3. 인증 시스템

### 3-1. 헤더

- 헤더 우측 상단에 "로그인" 버튼 추가
- 로그인 상태에서는 사용자 아이콘 또는 등급 배지로 UI 변경

### 3-2. 회원가입 페이지

- 입력 항목: 이메일, 아이디, 닉네임, 비밀번호, 비밀번호 확인
- 투자 경험 체크 질문 (등급 자동 분류용)

  ```
  Q1. 주식 투자 경험이 있으신가요?
      ① 없음  ② 1년 미만  ③ 1년 이상

  Q2. 다음 중 아는 용어를 모두 선택해주세요.
      □ 코스피  □ PER  □ 공매도  □ 데드 스파이럴  □ EB(교환사채)

  등급 분류 로직 (예시, 팀 확정 필요)
  - Q1=①, Q2 선택 0~1개 → 애기 개미
  - Q1=②, Q2 선택 2~3개 → 청년 개미
  - Q1=③, Q2 선택 4개 이상 → 고참 개미
  ```

### 3-3. 로그인 페이지

- 입력 항목: 아이디, 비밀번호

### 3-4. 아이디 찾기 페이지

- 입력 항목: 이메일
- 응답 방식: 해당 이메일로 가입된 아이디를 이메일로 전송 (화면에
  직접 노출하지 않음 — 이메일 소유 여부 검증 없이 노출 시 보안 취약)
- 화면 안내 문구: "입력하신 이메일로 아이디를 전송했습니다"

### 3-5. 비밀번호 찾기 페이지

- 입력 항목: 아이디, 이메일
- 응답 방식: 이메일로 임시 비밀번호 전송
- 임시 비밀번호로 로그인 시, 다른 페이지 접근을 차단하고 비밀번호
  변경 페이지로 강제 리다이렉트

### 3-6. 마이페이지

- 닉네임, 이메일, 등급(애기/청년/고참 개미) 표시
- 등급 재검사 링크 (투자 경험 질문 재응시 → 등급 재분류)
- 비밀번호 변경 페이지 이동 링크
- 굴 파기 기록 (4번 항목 참조)

### 3-7. 비밀번호 변경 페이지

1. 현재 비밀번호 입력
2. 서버에서 현재 비밀번호 일치 여부 확인
3. 일치 시 → 새 비밀번호 입력 + 새 비밀번호 확인 필드 노출
4. 확인 버튼 클릭 → 새 비밀번호로 업데이트

## 4. 마이페이지 — 굴 파기 기록 (출석 히트맵)

**컨셉**

- GitHub 컨트리뷰션 그래프를 개미굴 세계관으로 재해석한 출석 기록

**비주얼**

- 캘린더 히트맵, 흙색 계열 그라데이션 (굴을 파 들어가는 느낌)

  | 방문 슬롯 수 | 색상 톤                         |
  | ------------ | ------------------------------- |
  | 0/8          | 가장 옅은 베이지 (미방문, 겉흙) |
  | 1-2/8        | 연한 황토색                     |
  | 3-4/8        | 중간 갈색                       |
  | 5-6/8        | 진한 갈색                       |
  | 7-8/8        | 가장 진한 흙갈색 (깊이 판 굴)   |

- 평일(월-금)만 색상 표시 대상, 주말은 별도 톤(예: 회색 줄무늬)으로
  "장 없음" 표시

**카운트 조건 (핵심 로직)**

- 대상: 로그인한 사용자만
- 카운트 시점: 사용자가 실시간 페로몬의 특정 슬롯 콘텐츠에 진입한
  "그 순간의 현재 시각"이, 해당 슬롯의 유효 시간대 범위 안에 있을
  때만 카운트
- 지난 시간대 슬롯을 나중에 열람해도 카운트되지 않음
  (예: 15시에 09:30 슬롯 열람 → 카운트 X)
- 같은 슬롯을 유효 시간대 안에서 여러 번 봐도 중복 카운트 없음
  (하루 한 슬롯당 최대 1회)

**슬롯별 유효 시간대**

| 슬롯                 | 유효 시간대                      |
| -------------------- | -------------------------------- |
| 07:30 글로벌 시황    | 07:30 ~ 08:29                    |
| 08:30 NXT 프리마켓   | 08:30 ~ 09:29                    |
| 09:30 장초반 흐름    | 09:30 ~ 11:59                    |
| 12:00 오전장 흐름    | 12:00 ~ 13:59                    |
| 14:00 오후장 흐름    | 14:00 ~ 15:29                    |
| 15:30 장 마감        | 15:30 ~ 17:29                    |
| 17:30 애프터마켓     | 17:30 ~ 19:59                    |
| 20:00 오늘 시장 분석 | 20:00 ~ 23:59 (당일 자정 전까지) |

**데이터 구조**

- `user_id`, `date`, `visited_slots` (그날 카운트된 슬롯 목록, 예:
  `["07:30", "09:30", "15:30"]`)
- 진하기(0~8단계)는 `visited_slots` 길이로 프론트에서 계산 가능

**인터랙션**

- 칸에 마우스 hover 시 툴팁: "9/16 (수) · 5/8 확인 · 07:30, 09:30,
  12:00, 14:00, 15:30"
- 오늘 날짜 칸은 슬롯 방문 즉시 실시간으로 진하기 반영
