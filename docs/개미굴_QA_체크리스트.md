# 개미굴 — QA 체크리스트

이번에 구현한 기능(용어 사전·즐겨찾기, 플로팅 챗, 인증, 등급 시스템, 굴 파기 기록, 다크모드,
회원 탈퇴) 기준 확인 항목. 체크박스는 QA 진행하면서 그대로 체크해나가면 됨.

---

## 1. 회원가입 → 온보딩

- [ ] 회원가입 화면엔 기본 정보(이메일/아이디/닉네임/비밀번호/비밀번호 확인)만 보이고 퀴즈 문항은 없음
- [ ] 닉네임 9자 이상 입력 시도 시 8자에서 더 안 늘어남
- [ ] 비밀번호 8자 미만 / 영문+숫자 미포함 시 에러
- [ ] 비밀번호 ≠ 비밀번호 확인 시 에러
- [ ] 이미 가입된 이메일/아이디로 가입 시도 시 에러(409)
- [ ] 가입 성공 시 "회원가입이 완료됐어요! 다음은 등급 진단 퀴즈예요" 화면 노출 (자동 리다이렉트 아님)
- [ ] "등급 진단 퀴즈 풀러 가기" 클릭 시 `/onboarding/grade-quiz`로 이동
- [ ] 가입 직후 헤더에 즉시 로그인 상태(아바타+닉네임+등급 배지)로 바뀜

## 2. 등급 진단 퀴즈 (온보딩 + 마이페이지 재검사 공용)

- [ ] 문제가 한 번에 하나씩만 보임(전체 문항 한 화면 X)
- [ ] 진행률 "N/10번 문제" + 퍼센트 + 진행 바 정상 표시
- [ ] 1단계(Q1)에서만 "정확한 순위를 매기는 게 아니라..." 목적 안내 문구 노출
- [ ] 답 안 고르면 "다음" 버튼 비활성
- [ ] "이전" 버튼으로 되돌아가도 이전 답이 유지됨
- [ ] 진행 중 새로고침/탭 닫기 시도 시 브라우저 이탈 확인창 뜸
- [ ] 마지막 문제에서 버튼 텍스트가 "결과 보기"로 바뀜
- [ ] 결과 화면에 "{닉네임}님은 총 N점 (M문제 중)! 등급은 OOO입니다" 정확히 표시
- [ ] 온보딩에서 완료 시 "메인으로 가기" 클릭 → 홈으로 이동
- [ ] 마이페이지 재검사에서 완료 시 카드 안으로 복귀(별도 페이지 이동 아님) + 등급/이력 즉시 갱신
- [ ] 마이페이지 재검사 중 "취소하고 돌아가기"로 빠져나갈 수 있음

## 3. 로그인 / 로그아웃 / 세션

- [ ] 잘못된 아이디·비밀번호 → 어느 쪽이 틀렸는지 구분 안 되는 공통 에러 메시지
- [ ] 로그인 성공 시 헤더가 [아바타][닉네임님][등급 배지] 순서로 즉시 반영
- [ ] 새로고침해도 로그인 상태 유지(세션 쿠키)
- [ ] 로그아웃 시 헤더가 "로그인" 버튼으로 복귀, `/mypage` 접근 시 `/login`으로 튕김
- [ ] 로그인 안 한 상태로 `/mypage`, `/change-password`, `/onboarding/grade-quiz` 직접 접근 시 `/login`으로 이동

## 4. 아이디/비밀번호 찾기 · 비밀번호 변경

- [ ] 아이디 찾기: 가입 안 된 이메일 넣어도 동일한 성공 메시지(계정 존재 여부 노출 안 됨)
- [ ] 비밀번호 찾기: 아이디+이메일 불일치해도 동일한 성공 메시지
- [ ] (현재 SMTP 미연동 상태) 서버 로그에 아이디/임시 비밀번호가 실제로 찍히는지 - 백엔드 로그 확인
- [ ] 임시 비밀번호로 로그인 시 무조건 `/change-password`로 강제 이동
- [ ] 강제 이동 상태에서 다른 페이지(URL 직접 입력 포함) 접근 시도해도 계속 `/change-password`로 튕김
- [ ] 비밀번호 변경 1단계(현재 비밀번호 확인) 통과해야 2단계(새 비밀번호) 입력칸 노출
- [ ] 현재 비밀번호 틀리면 1단계에서 에러, 2단계로 안 넘어감
- [ ] 변경 완료 후 must_change_password 강제 이동이 풀림(다른 페이지 자유 이동 가능)
- [ ] 모든 input에 placeholder 노출

## 5. 마이페이지 — 내 정보

- [ ] 닉네임/이메일/가입일/등급 배지 정상 표시
- [ ] 활동 데이터 부족 시 "등급 재검사 하기" 링크가 눈에 띄게 노출
- [ ] 활동 데이터 충분(출석 15일 이상 또는 용어 4개 이상 열람) 시 진행 상황 텍스트로 대체되고 재검사는 보조 링크로 축소
- [ ] "등급 변경 이력"에 퀴즈 제출/활동 승급 수락 이력이 최신순으로 쌓임
- [ ] 버튼(비밀번호 변경/로그아웃) 높이가 시각적으로 동일(40px)

## 6. 등급 시스템 — 활동 기반 승급 제안

- [ ] 실시간 페로몬 슬롯 유효 시간대 안에 진입 시에만 출석 카운트(지난 시간대 열람은 카운트 안 됨)
- [ ] 같은 슬롯 하루 중복 열람해도 중복 카운트 안 됨
- [ ] 용어 사전 카드가 화면에 스크롤되어 들어오면 열람 기록됨(로그인 시에만)
- [ ] 출석 15일 + 용어 4개(애기→청년), 출석 22일 + 용어 6개(청년→고참) 조건 충족 시 챗에 승급 제안 카드 노출
- [ ] 같은 등급으로는 승급 제안이 한 번만 옴(수락/보류 상관없이 재제안 안 됨)
- [ ] "승급하기" 클릭 시 즉시 등급 반영(헤더 배지 포함), 카드 사라짐
- [ ] "나중에" 클릭 시 카드만 사라지고 등급은 안 바뀜, 이후 다시 안 뜸

## 7. 굴 파기 기록 (출석 히트맵)

- [ ] 안내 문구("시황 타임라인의 각 시간대(하루 8번)에...") 노출
- [ ] 히트맵 색 5단계(0/1-2/3-4/5-6/7-8) + 주말 회색 줄무늬 정상 표시
- [ ] 칸에 마우스 올리면 "M/D (요일) · N/8 확인 · HH:MM, ..." 툴팁 노출
- [ ] 연도 이전/다음 이동 시 데이터 갱신
- [ ] 오늘 칸이 슬롯 방문 즉시 진해짐(새로고침 없이는 다음 방문 시 반영 확인)

## 8. 개미 용어 사전 + 즐겨찾기

- [ ] 24개 용어 전부 정상 노출(검색/톤 필터 모두에서)
- [ ] 톤 필터(전체/애기/청년/고참) 전환 시 카드 목록은 그대로, 설명 문구만 바뀜
- [ ] 안내 문구("버튼을 누르면 용어는 그대로...") 노출
- [ ] 로그인한 유저는 첫 진입 시 본인 등급에 맞는 톤이 기본 선택돼 있음
- [ ] 등급 재검사로 등급이 바뀐 뒤 다시 용어 사전 들어가도 새 등급 기준 톤이 기본값으로 반영
- [ ] 검색 시 용어명 기준 필터링, 관련 태그 클릭 시 해당 용어로 검색
- [ ] 로그인 안 한 상태에서 별(★) 클릭 → `/login`으로 이동
- [ ] 로그인 상태에서 별 클릭 → 즉시 채워짐(토글), 새로고침해도 상태 유지
- [ ] 마이페이지 "즐겨찾는 용어"에 즐겨찾은 용어가 실시간 반영
- [ ] 즐겨찾기 0개일 때 안내 문구 + "개미 용어 사전으로 가기" 버튼 노출

## 9. 불개미 대장 챗 (플로팅)

- [ ] 모든 서브 페이지에서 우측 하단 플로팅 버튼 노출(데스크톱/모바일 공통)
- [ ] 열었을 때 배경 블러/딤 처리 없음(페이지 콘텐츠 그대로 보임)
- [ ] 새 브리핑 메시지 도착 시 빨간 안읽음 배지(숫자) 노출, 열면 사라짐
- [ ] 배지 카운트가 새로고침 후에도 "마지막으로 본 시점 이후 것"만 정확히 집계
- [ ] 승급 제안이 있으면 챗 맨 위 고정 카드로 노출(브리핑 메시지와 섞이지 않음)
- [ ] 버튼에 승급 제안 전용 배지(그 외 안읽음 배지와 다른 위치/색)

## 10. 다크모드

- [ ] 헤더 토글 클릭 시 즉시 전환, 새로고침/재방문해도 유지
- [ ] 로그인/회원가입/온보딩/마이페이지/용어사전 — 다크에서 텍스트 대비·카드 스타일 정상
- [ ] 기존 라이트 전용 카드(홈 대시보드 등)가 흰 배경이라도 텍스트가 안 보이는 등 "읽을 수 없는" 상태는 없음 (톤 안 맞는 건 알려진 상태, 후속 마이그레이션 예정)
- [ ] 시스템(OS) 다크모드 설정과 무관하게 유저가 고른 값이 우선

## 11. 회원 탈퇴

- [ ] "회원 탈퇴" 클릭 시 먼저 사유 선택 팝업이 뜸(바로 최종 확인 아님)
- [ ] 사유 미선택 시 "다음" 비활성
- [ ] "기타" 선택 후 텍스트 미입력 시 "다음" 비활성, 입력하면 활성화
- [ ] 사유 "다음" → 최종 확인 팝업("정말 개미굴을 나가시겠어요?") 전환
- [ ] 최종 확인에서 "아니오" → 완전히 닫힘(사유 선택 처음부터 다시 해야 함)
- [ ] "네, 탈퇴할게요" → 실제 계정 삭제, 홈으로 이동, 로그아웃 상태로 헤더 복귀
- [ ] 탈퇴한 계정으로 재로그인 시도 시 실패(계정 자체가 없음)
- [ ] 탈퇴 사유는 계정 삭제와 무관하게 별도 저장(개발 확인용 - DB `withdrawal_feedback` 테이블에 user_id 없이 남아있는지)

## 12. 크로스 커팅

- [ ] 로컬 프론트(localhost:3000) ↔ 백엔드(localhost:8000) 간 쿠키 정상 동작(로그인 유지)
- [ ] 모바일 폭(375~430px)에서 헤더/사이드바/챗/마이페이지 레이아웃 깨짐 없음
- [ ] 백엔드 CORS: GET/POST/DELETE 전부 정상 통과(신규 엔드포인트 추가 시 메서드 빠뜨리지 않았는지 재확인)
- [ ] 콘솔에 예상 밖 401/404/500 없는지(로그인 전 정상적으로 뜨는 401은 제외)
